Name

Voice
Test plays a cached signature line first (your cloned voice once cloning is done), then the live voice (Kokoro → Piper fallback). Repeated replies ("Okay.", "Done.") play instantaneously from the signature cache; streaming replies use the live voice.
Voice cloning
Record ~20 s of your own speaking normally (only voices you have consent to clone), then regenerate every cached signature line in that voice — all local.
Microphone
"Windows default microphone" uses the OS default input. Applies immediately.
Sensitivity

In-session 0.007
